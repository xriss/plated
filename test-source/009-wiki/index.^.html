#^body form=wiki # title text This is a quick link to a file /Page1 this is/not pre formated code type stuff /page2 anywhere can contain links as they are processed after wiki conversion and they can be absolute //009-wiki/page3 like so. To disable quick links in text just use another chunk with form=markdown and include it We can also link to dir with a trailing slash like /Page4/ which will of course use the index.html inside the dir. Links to images such as /test.png can be upgraded to inline with some simple javascript. See ^.html for example. Links are forced to lowercase only, but capitals can be used for display text. All we are doing here is adding a simple way to put obvious quick links between pages into markdown text.
